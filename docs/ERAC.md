# ERAC — 현재 기관 설정

2026-09-28 사용자 지정. 원작의 ERAC 설명을 대체하는 프로젝트 고유 설정이다.

- 정식 명칭: 황실 이상현상 연구청
- 영문 명칭: Extranormal Research Agency of the Crown
- 약칭: ERAC
- 기관 성격: 전후 대륙에서 발생한 이상현상에 전문적으로 대항하기 위해 만들어진 신비 연구 기관
- 라이카: 27세. ERAC 조사 1팀 팀장, 직업은 학자. 사용자 요청으로 나이를 20대로 낮췄으며 나머지 인물 설정과 외형은 유지.
- 본명: 스칼릿 그레이스(Scarlet Grace). 코드네임: 라이카(Laika). 기존 서술에서 라이카는 코드네임으로 해석하며 프로젝트 이름과 /Laika/ 주소는 유지한다.
- 라이카의 출신: 대영제국. 사용자 지정 인물 정보이며, 이 결정만으로 ERAC의 황실 소속 국가나 기존 설립 배경을 변경하지 않는다.
- 변경: 왕실 → 황실, 고대신비 연구 → 전후 이상현상 대응. '대륙의 마법 학회에 대항하여 설립된 대영제국 기관'이라는 기존 기원은 더 이상 프로젝트 기관 설명에 적용하지 않는다.
- 미정: 전쟁의 명칭·연대·교전 세력, 대륙명, 황실의 국명과 통치자. 임의로 대영제국이나 다른 국가로 확정하지 않는다.

원작 조사 노트는 원문 확인 기록이므로 옛 명칭을 그대로 보존하며, 현재 프로젝트 설정과 혼동하지 않는다. 별도 ERAC 폴더의 15인 사이트는 분리 시점 보존본이다. 후속 제작 시 이 설정을 적용한다.
