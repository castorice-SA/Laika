# Raika

Raika는 「평행지구의 탐정님」 세계관을 기반으로 한 인물 기록 사이트입니다. 프로젝트 이름은 **Raika**로 유지하며, 라이카를 포함한 15명의 인물 명단을 제공합니다. 외부 의존성 없이 바로 실행되는 정적 웹사이트입니다.

## 확정된 방향과 참고 자료

- 대상: 라이카의 프로필 및 사용자가 지정한 15명의 인물 명단
- 사용자가 정한 주제: 「평행지구의 탐정님」
- 참고 원작의 게시글 제목: 「[인터랙티브/interactive]탐정 양은 ■■을 공상합니다 ver.β」
- 사용자 제공 참고 글: https://arca.live/b/cyoa/146611295
- 사용자 제공 참고 글: https://arca.live/b/cyoa/146491816
- 연결된 CYOA: https://stalight774.neocities.org/detectives_XXX/

원작의 공통 설정과 라이카 개인의 설정은 구분합니다. 사용자가 인물 소개의 자율 창작을 요청하여 라이카를 실종과 기억 관련 사건을 추적하는 탐정으로 작성했습니다. 조용한 태도, 건조한 농담, 수첩으로 판단을 검토하는 습관, 동행인을 챙기는 행동과 의뢰인의 남겨진 사람에게 결과를 전하는 원칙은 이 프로젝트에서 창작한 설정입니다. 원작에서 확인된 사실로 취급하지 않습니다. 능력, 소속 및 관계는 아직 정하지 않았으며 CYOA 도입부에 등장하는 인물과 동일 인물로 간주하지 않습니다.

### 화면 방향 및 캐릭터 이미지

화면은 PDA에서 조회하는 인물 기록 형식입니다. 방문자에게 사이트나 제작 과정을 설명하는 문구는 사용하지 않습니다. 접속 화면(`index.html`), 인물 명단(`characters.html`), 라이카 기록(`profile.html`)은 별도 페이지입니다. 접속 화면에는 사용자가 지정한 프랑스어·영어 시작 문구와 한국어 번역을 표시하며, ‘접속하기’ 버튼으로 인물 명단을 엽니다. 실제 계정 인증 기능은 없습니다. 배경은 먹색, 패널은 어두운 회색이며 금빛과 발광을 줄인 저채도 테마입니다.

인물 순서는 라이카, 펠리세트, 벨카, 스트렐카, 비온, 알리비나, 에노스, 아니타, 엑토르, 크라사프카, 도치카, 데지크, 아브레크, 리시치카, 체르누시카입니다. 이름 표기는 사용자가 제공한 그대로 유지합니다. 15명 모두 개별 기록 주소로 연결되며, 프로필의 이전·다음 화살표로 순환 이동합니다. 라이카 외 14명은 이름만 등록되어 있습니다. 임의의 이미지·소개·관계 설정은 추가하지 않았습니다.

사용자가 라이카의 외형으로 제공한 이미지 7장을 `assets/raika/`에 보관했습니다. 번호는 제공 순서와 같습니다. 02번을 대표 사진으로 사용하고 나머지 6장은 접을 수 있는 첨부 이미지 영역에 표시합니다. 원본의 비율을 유지합니다.

이미지에서 관찰되는 외형은 은백색 장발, 연보라색 눈, 검은 리본, 남색 코트, 흰 셔츠, 검은 타이입니다. 화면의 외형 식별란은 사용자 요청으로 인물 소개로 교체했습니다. 직책은 소개에 맞춰 탐정으로 표시하며 나이·소속은 미등록입니다. 창작한 소개는 확인한 현대 판타지·아포칼립스 배경, 기억 이상이 등장하는 도입부와 사용자가 고른 시작 문구를 바탕으로 합니다.

## 배포

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 배포 대상으로 사용합니다. 별도 빌드나 외부 라이브러리 없이 정적 파일을 제공하며, `.nojekyll`로 Jekyll 처리를 생략합니다. 코드 변경을 `main`에 업로드하면 Pages가 갱신됩니다.

## 구조

```text
Raika/
├── index.html    # PDA 접속 화면과 시작 문구
├── characters.html # 15명의 인물 명단
├── profile.html  # 라이카 인물 기록과 첨부 이미지
├── styles.css    # 반응형 화면 스타일
├── script.js     # 인물 선택과 이전·다음 탐색
└── README.md     # 프로젝트 안내
```

프로필 전환에는 JavaScript가 필요합니다. 잘못된 인물 주소에는 기록 없음 안내를 표시합니다.

사이트와 캐릭터 창작의 작업 기준은 [PROJECT-PLAN.md](PROJECT-PLAN.md)에 정리했습니다.
