# Raika

Raika는 「평행지구의 탐정님」 세계관을 기반으로 한 인물 기록 사이트입니다. 프로젝트 이름은 **Raika**로 유지하며, 라이카를 포함한 15명의 인물 명단을 제공합니다. 외부 의존성 없이 바로 실행되는 정적 웹사이트입니다.

이야기 제목과 화면 표기는 **ERAC — 미종결 기록**입니다. 캐릭터명 라이카와 저장소명·배포 주소 Raika는 유지합니다. 종결된 조사에서 아무도 찾지 않는 한 사람을 라이카가 계속 찾는 서사를 채택했습니다. 이는 사용자 승인에 따른 프로젝트 창작이며 원작의 공식 사건이 아닙니다. 확정 내용과 미정 사항은 [서사 기준](docs/STORY.md)에 기록합니다.

### 화면 방향 및 캐릭터 이미지

화면은 PDA에서 조회하는 인물 기록 형식입니다. 방문자에게 사이트나 제작 과정을 설명하는 문구는 사용하지 않습니다. 접속 화면(`index.html`), 인물 명단(`characters.html`), 라이카 기록(`profile.html`)은 별도 페이지입니다. 접속 화면에는 사용자가 지정한 프랑스어·영어 시작 문구와 한국어 번역을 표시하며, ‘접속하기’ 버튼으로 인물 명단을 엽니다. 실제 계정 인증 기능은 없습니다. 배경은 먹색, 패널은 어두운 회색이며 금빛과 발광을 줄인 저채도 테마입니다.

인물 순서는 라이카, 펠리세트, 벨카, 스트렐카, 비온, 알리비나, 에노스, 아니타, 엑토르, 크라사프카, 도치카, 데지크, 아브레크, 리시치카, 체르누시카입니다. 이름 표기는 사용자가 제공한 그대로 유지합니다. 전원 ERAC 조사 1팀 구성원이며 라이카가 팀장, 펠리세트가 부팀장입니다. 사용자 요청으로 15명의 직업·나이·역할·성격·이력·조사 수단·한계·관계·사건 입장을 작성했습니다. 프로필의 이전·다음 화살표와 관계 링크로 인물 간 이동이 가능합니다. 개별 데이터는 `characters-data.js`, 전체 설정은 [조사 1팀 설정집](docs/TEAM-01.md)에 있습니다. 나머지 14명의 이미지는 아직 없습니다.

사용자가 라이카의 외형으로 제공한 이미지 7장을 `assets/raika/`에 보관했습니다. 번호는 제공 순서와 같습니다. 02번을 대표 사진으로 사용하고 나머지 6장은 접을 수 있는 첨부 이미지 영역에 표시합니다. 원본의 비율을 유지합니다.

이미지에서 관찰되는 외형은 은백색 장발, 연보라색 눈, 검은 리본, 남색 코트, 흰 셔츠, 검은 타이입니다. 라이카는 31세 학자이자 조사 1팀 팀장으로 작성했습니다. 직업과 직책을 별도로 표시하고 직업 아래 짧은 설명을 붙입니다. 연령과 팀 편성은 프로젝트 창작 설정이며 원작 공통 사실이 아닙니다.

## ERAC 접속 표지

접속 화면에 프로젝트용 ERAC 문장을 적용했습니다. 문서 번호, 내부 열람용 표기, 기록 분류와 읽기 전용 표시를 갖춘 PDA 문서 표지이며 《미종결 기록》 제목과 기존 시작 문구·번역을 표시합니다. 문장과 문서 식별 체계는 프로젝트의 창작 연출이며 원작 공식 설정이 아닙니다. 이 화면의 ‘내부 열람용’은 실제 접근 제한이나 보안을 의미하지 않습니다. 접속 버튼은 기존 인물 명단으로 이동합니다.

로고 원본과 생성 기록은 `assets/erac/`에 보관합니다.

## 배포

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 배포 대상으로 사용합니다. 별도 빌드나 외부 라이브러리 없이 정적 파일을 제공하며, `.nojekyll`로 Jekyll 처리를 생략합니다. 코드 변경을 `main`에 업로드하면 Pages가 갱신됩니다.

## 구조

```text
Raika/
├── index.html    # PDA 접속 화면과 시작 문구
├── characters.html # 15명의 인물 명단
├── profile.html  # 라이카 인물 기록과 첨부 이미지
├── styles.css    # 반응형 화면 스타일
├── script.js     # 프로필 렌더링과 인물 탐색
├── characters-data.js # 15명 인물 데이터
├── docs/TEAM-01.md # 팀 설정과 전체 인물 설정집
├── tests/characters.test.cjs # 데이터 및 화면 연결 검사
└── README.md     # 프로젝트 안내
```

프로필 전환에는 JavaScript가 필요합니다. 잘못된 인물 주소에는 기록 없음 안내를 표시합니다.

`node tests/characters.test.cjs`로 15명 데이터, 명단 표기, 관계 링크와 프로필 전환을 검사합니다. 인물 데이터를 수정할 때 명단 카드와 설정집도 함께 동기화합니다.

사이트와 캐릭터 창작의 작업 기준은 [PROJECT-PLAN.md](PROJECT-PLAN.md)에 정리했습니다.
