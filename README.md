# Raika

Raika는 한 캐릭터의 설정과 이야기를 보여주는 캐릭터 프로필 사이트입니다. 현재는 외부 의존성 없이 바로 실행되는 최소 웹 골격만 포함합니다.

## 로컬에서 보기

`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다. 로컬 서버를 사용하려면 프로젝트 폴더에서 원하는 정적 파일 서버를 실행하세요.

## 구조

```text
Raika/
├── index.html    # 기본 페이지와 문서 메타데이터
├── styles.css    # 반응형 화면 스타일
├── script.js     # 최소 브라우저 동작
└── README.md     # 프로젝트 안내
```

## 다음 단계

1. 캐릭터의 이름, 별칭과 한 줄 소개를 정합니다.
2. 기본 정보, 성격, 배경과 관계 설정을 정리합니다.
3. 대표 이미지와 갤러리 구성을 설계합니다.
4. 실제 설정에 맞춰 화면과 필요한 기능을 단계적으로 추가합니다.
