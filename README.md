# Laika

영문명과 공개 저장소 이름은 사용자 요청으로 Raika에서 Laika로 변경했습니다. 공개 주소는 /Laika/입니다. 작업 연결을 유지하기 위해 로컬 폴더명 Raika와 기존 이미지 파일 경로 assets/raika/는 그대로 두었습니다. 이는 화면에 표시되는 이름과 무관합니다.

현재 기관 설정: **황실 이상현상 연구청 — Extranormal Research Agency of the Crown (ERAC)**. 전후 대륙에서 발생한 이상현상에 전문적으로 대항하기 위해 설립된 신비 연구 기관이다. 원작과 구분되는 사용자 지정 설정이며 [기관 설정](docs/ERAC.md)을 따른다.

라이카 개인 프로필 전용 정적 사이트. 기존 프로젝트명과 GitHub Pages 주소를 유지합니다.

- 공개 주소: https://castorice-sa.github.io/Laika/
- 접속 화면 → 라이카 프로필. 명단과 다른 인물 전환은 제공하지 않습니다.
- ERAC 문장, 어두운 PDA 디자인, 시작 문구와 한국어 번역, 라이카 이미지 7장을 유지합니다.
- 라이카는 27세 학자이자 ERAC 조사 1팀 팀장입니다.
- 인물 소개는 승인된 '차분하고 다정하지만 진실 앞에서는 잔인해질 수 있는 학자형 탐정' 방향입니다.
- 실제 로그인이나 접근 제한은 없습니다.

## 디자인

먹색 바탕에 회청색 문서 패널, 바랜 자주색 강조와 은빛 테두리를 적용했습니다. 접속 표지의 문장 프레임, 세리프 영문 제목, 문서 모서리 장식, 프로필 초상 프레임과 번호가 있는 기록 패널을 사용합니다. 기존 설정과 인용문은 유지하며 외부 폰트·라이브러리·추가 이미지 없이 CSS로 표현합니다. 상단에서 세부 기록과 첨부 이미지로 이동할 수 있습니다.

390px/320px 모바일, 기본 1280px 데스크톱, 3440px 울트라와이드에서 레이아웃을 검사했습니다. 모바일에서는 패널을 한 열로 정렬하고, 모션 감소 설정에서는 부드러운 스크롤과 전환 효과를 끕니다.

## 두 사이트 분리

기존 15인 사이트 전체는 같은 작업공간의 별도 `../ERAC/` 폴더에 복사하고 23개 파일의 해시 일치를 확인했습니다. 별도의 Git 저장소나 공개 주소는 아직 만들지 않았습니다. 두 번째 사이트의 정식 이름과 배포는 후속 작업입니다.

이 저장소의 `docs/TEAM-01.md`, `docs/STORY.md`는 분리 전 설정 보존본입니다. 현재 공개 프로필의 기준은 `profile.html`이며, 과거 초안과 충돌하면 현재 프로필을 우선합니다. '잔향 중계소' 사건은 이번 개인 프로필에 싣지 않았습니다. 인물 설정과 ERAC 로고는 프로젝트 창작이며 원작 공식 설정으로 취급하지 않습니다. 원작 조사 범위는 `docs/WORLD-RESEARCH.md`에 있습니다.

## 실행 및 검사

`index.html`을 브라우저에서 열면 됩니다. JavaScript 없이 프로필과 갤러리를 열람할 수 있습니다.

`node tests/characters.test.cjs`로 단일 프로필, 접속 연결, 이전 명단 주소의 이동 안내, 이미지 경로를 검사합니다. 두 번째 사이트의 기존 15인 검사는 ERAC 폴더에서 같은 명령으로 실행합니다.

## 파일

- `index.html`: 접속 화면
- `profile.html`: 라이카 개인 프로필
- `characters.html`: 이전 명단 주소 호환용 이동 페이지
- `styles.css`: 반응형 PDA 스타일
- `assets/`: 기존 로고 및 사용자 제공 이미지
- `docs/`: 세계관 조사와 이전 설정 보존본

기존 `profile.html?character=...` 주소도 라이카 단일 기록을 표시합니다. GitHub Pages는 main 브랜치 루트를 배포하며 별도 빌드가 필요하지 않습니다.
